# Retail-Business-Performance-Analysis

## 📌 Project Overview
This project analyzes transactional retail data to uncover insights related to profit margins, inventory turnover, and seasonal sales trends. The goal is to identify profit-draining product categories, optimize inventory, and improve overall retail performance.

## 🧰 Tools Used
- Python (Pandas, Seaborn, Matplotlib)
- SQL (MySQL)
- Power BI

## 📈 Key Metrics & Visuals
- Total Sales, Quantity Sold, Transactions, Avg. Unit Price, and Customers
- Monthly Sales Trends
- Sales by Country and Weekday
- Product-level Quantity Sold
- Inventory Turnover Rate
- Correlation between Profitability and Inventory Days

## 📂 Project Workflow
1. Data Cleaning and Preprocessing (Python)
2. Exploratory Data Analysis and Visualizations (Python)
3. SQL Queries for Business Metrics
4. Power BI Dashboard Creation
5. Strategic Insights and Reporting

## 📝 Deliverables
- Power BI Dashboard (.pbix)
- SQL Scripts (.sql)
- python file (.ipynb)
- Project Report (PDF,PPT)
- Dataset (Excel)

## 📌 Conclusion
This project provides a clear overview of retail performance and helps stakeholders identify areas for cost reduction and strategic improvements.
